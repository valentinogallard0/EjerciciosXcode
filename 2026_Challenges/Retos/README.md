# Retos

Esta carpeta existe para los retos nuevos que se vayan creando dentro del proyecto.

## Convencion

Cada reto debe vivir en una carpeta propia con esta idea de nombre:

- `YYYY/YYYY-MM-DD_slug-del-reto`

Ejemplo:

- `2026/2026-04-11_login-con-validacion`

## Archivos Esperados

Cada carpeta de reto debe contener por lo menos:

- `RETO.md`: propuesta del reto
- `PROGRESO.md`: notas, decisiones, dudas y bloqueos
- `RETRO.md`: retroalimentacion despues de la revision

## Intencion

La idea no es solo guardar enunciados. Esta carpeta debe ayudar a convertir la practica en un proceso repetible:

- pedir reto
- resolverlo
- recibir revision
- mejorar criterio tecnico
